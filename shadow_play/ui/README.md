# 影境 · 本地 UI 原型

直接用现代浏览器打开 `index.html` 即可体验；不需要安装依赖、构建或部署。也可以在本目录运行 `python -m http.server 4173 --bind 127.0.0.1`，访问 `http://127.0.0.1:4173`。

## 页面和交互

- `#home`：动态首页、原创 SVG 皮影戏台、三个模式入口；右上角可暂停界面动效。
- `#classic`：武松打虎屏幕预演，播放 / 暂停、重播、拖动进度、六个剧情入口。总时长采用当前剧情的 **67.10566893424036 秒**；六幕是界面分组，动画是独立绘制的概念表达，不是设备路线复现。此版没有音轨。
- `#touch`：鼠标或触摸拖动武松双手及颈部主杆，映射到 SVG 皮影；支持方向键调节、四个姿态预设、恢复初始姿态。坐标仅表示屏幕插画位置。
- `#pose`：12 秒、三个阶段的示范姿态与皮影映射，可以暂停、继续和重播；没有访问摄像头或运行姿态识别。

## 设计

深木色 `#21160f`、旧纸黄 `#c7a56b`、暗朱砂 `#8e3021` 和铜金色。采用木框戏台、旧戏本封面、纸张纤维、折痕、污渍和印章表达传承感。楷体标题与无衬线功能文字搭配；本机字体回退，无远程字体请求。插画均为代码绘制的 SVG。人物与老虎的配色、服饰、虎纹和长尾参照用户提供的两张实物图重新绘制；原始照片没有嵌入 UI 或纳入 Git。

三个模式入口及模式间切换都有约 3.2 秒的旧纸掀开动画：先显示该模式的折次、竖排标题和朱印，再从右向左翻开；纸页右边带炭化裂口、橙红余烬和小火苗，随纸页一起翻动。初次直接打开模式链接不播放转场。Esc 可跳过；关闭界面动效或系统设置减少动态效果时跳过转场。动画结束、取消、切换页面或后台挂起时清理遮罩和交互锁，另有超时收尾。

主页两侧有细窄的燃烧边缘，30 枚火星缓慢向下飘落；手机端减为 15 枚。所有装饰均由 SVG / CSS 绘制，忽略鼠标与触摸事件。暂停界面动效同时暂停火苗与火星；系统减少动态效果时隐藏粒子和火苗、保留静态余烬；切换到模式页面后隐藏主页特效，页面在后台时暂停主页特效。

## 实物连接点对应

点位语义来自 `../docs/hardware_motor_protocol.md`、`../docs/mapping.md`。共五根杆：

| 标识 | UI 与实物对应位置 |
| --- | --- |
| `wusong_neck` | 武松颈部主杆；不再把腰或骨盆作为控制点 |
| `wusong_left` | 武松自身左手；正面火柴人中显示在画面右侧 |
| `wusong_right` | 武松自身右手；正面火柴人中显示在画面左侧 |
| `tiger_head` | 老虎耳部的头杆连接点，不是鼻尖 |
| `tiger_tail` | 尾部后端杆连接点；不是新增的独立尾尖执行器 |

`rig.js` 集中定义标识与插画锚点。UI 插画的手部点、杆线端点共用腕点；颈部杆从颈部出发。触控颈点移动时，腕部会重新求解以保持和对应火柴人手点一致；超出插画臂长时同时约束可见控制点，避免控制点与角色手部错位。体感示意的颈点取双肩中点，与现有视觉输入约定一致；这不是检测模型直接输出的真实颈部点。

首页保持简洁，经典、触控、体感界面显示相应连接点名称。老虎为在戏台上朝向武松而作左右镜像，头杆与尾杆的身份不交换；点随角色图形一起变换。触控与体感目前仍仅操控武松，老虎两点在经典页面展示。

截图只能确认部分外观及连接部位。被杆件遮挡的精确铰接中心、毫米坐标与实测轴角均未核验；SVG 中锚点是插画坐标，不是照片取点记录。没有借用旧机位标定或旧实机动作，也没有把插画姿态当作可执行路线。

适配桌面、横向触摸屏和平板；窄屏采用单列排版。遵循系统减少动态效果偏好，提供可见键盘焦点、对话框和触摸取消处理。切换模式会停止当前演示；隐藏页面和打开介绍弹窗时暂停演示计时。

## 边界

此目录为独立前端设计，不接入电机、PWM、板卡、相机、音频或现有动作路线；无 fetch、WebSocket、媒体设备或后端调用，不读取或改变动作锁。屏幕表现不代表机械可执行性或实机表演已经验证。真实硬件、人体识别与音频接入属于后续单独工作。

文件：`index.html` 是页面外壳，`styles.css` 是基础响应式样式，`heritage.css` 是旧戏台主题，`parchment.svg` 是原创纸纹，`transitions.js` 是掀纸转场，`rig.js` 是点位定义与屏幕坐标映射，`art.js` 是 SVG 插画，`app.js` 是路由和界面交互逻辑。点位映射检查运行 `node --test rig.test.js`。
