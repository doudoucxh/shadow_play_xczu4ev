# 识别模块更新 · r2

本包包含 2026-10-16 21:30（北京时间）发布记录对应的整套识别模块。

- 主模型：`ShadowSketch-MLP-48-agent-ui20-v2`，与上一部署包相同。
- 姿态分类：`ShadowSketchTopology-15-KNN3-agent-ui20-body-cross-v2`，替换上一包的旧版本。
- 几何解析：同步使用该次发布的 `sketch-geometry.js`，处理跨过躯干、双手同侧等路线。
- 画板坐标模块、动作目录和标准皮影姿势随包配套。

模型文件及配套模块的 SHA256 已对照项目发布记录核验，详情见 `VERSION.json` 和 `docs/recognition-release-manifest.json`。
实际嵌入网页中的模型也已检查，不能仅替换 source 目录后跳过重建。
回归检查记录在 `docs/MODEL_QA.json`；其中已有画稿重放和合成样本检查不代表独立真人识别准确率。

## 更新旧包

1. 关闭旧界面和它的网页服务，再解压本包；不要同时运行两个版本。
2. 按 `README_CN.md` 启动。浏览器配置目录和端口保持原值，可保留本机动作序列和画稿。
3. 启动脚本会比对网页内容校验值，避免误连接仍在运行的旧网页服务。端口被旧服务占用时会提示失败。
4. 新识别器加载旧画稿时会保留笔画，并要求重新识别；已存动作序列继续使用标准动作。

本次更新只核对和打包项目已发布的最新识别器，没有重新训练，也没有访问开发板。
