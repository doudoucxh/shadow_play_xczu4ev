# 人物三杆联动标定

人物左手、头部、右手三根杆共同约束皮影。右手单轴摆动可能经肩、腰和腿传递到整个人物；每个单轴分别可动，不代表这些单轴可以任意组合。

当前方法保留已核验的起点，比较同样的右手指令在头部杆固定、头部杆跟随、另一只手也跟随时的效果。观察腕部位移、头腰相对倾斜、下身姿态及回位余差。先把上下挥手与左右摆动分开，再验证组合。

`person_linkage_session.py` 只执行本次计划列出的固定六维偏移路径。偏移随同一个余弦进度同步变化，每轴每步不超过 1 μs，间隔至少 50 ms，终点保持 2 秒并沿原路径返回。每次新路径完成后要检查双视角，演示只能使用已检查的路径。

常规三杆对照保持 2/4 号固定。双手上下诊断须显式设置 `bilateral_hand_diagnostic=true`，才允许 2 号向负方向偏移（最多 −40 μs）、6 号向正方向偏移，两轴共享同一进度。4 号仍固定，老虎四路不启用；4 号的弱机械响应仍待排查。试验上限不是标定出的安全工作空间。没有轴角度反馈，也没有得到当前幕面的精确毫米坐标映射。

异常、取景失效或状态改变时停止 PWM，不盲目执行返回起点。全局事故锁保留。正常结束的寄存器、双视角姿态和现场连续操作条件一起作为下一次衔接的依据。

本轮实测结果和录像索引见 `person_linkage_result.20261012.json`。

这里的角度来自图像纹理旋转匹配，搜索步长为 3°，并非人体关节角度或实际舵机角度；像素也没有转换为毫米。三杆加上下挥手时，腰部纹理本身约有 −3° 的变化，因此上身相对腰部的外观转角约为 −3°。具体回位与重复结果保存在 JSON 中。

头部杆单独补偿能减少上身侧歪，但不能消除全身平移。上下轴加入之后，整个关节链的响应再次变化。因此“头部跟随量＝固定比例×右手角度”不能作为所有动作的通用公式。

本轮三杆挥手使用同一个进度 `s∈[0,1]`：1 号 `1537+round(10s)`，3 号 `1537+round(30s)`，5 号 `1508+round(40s)`，6 号 `1500+round(80s)`；2 号固定 1352，4 号固定 1574。只核验了这条同步曲线及反向返回，没有核验这几个范围组成的所有组合，也没有授权无人值守回放。

结束时序列为 11586，十路 PWM 均关闭，无故障，事故锁保留；老虎未启用。影像存放在 Git 忽略目录 `camera_liveview/output/person-linkage-demo-20261012-g/`。

## 三个控制点如何考虑其他关节

三根杆控制左手、头部、右手的连接点，其余肩、肘、腰、膝等关节受到相邻连接、重力和接头余量影响。三点位置相同也可能对应不同的被动关节姿态，不能假设它们完全由三点唯一确定。

人体姿态映射时，先确定躯干的全局位置和朝向，再以躯干为参考生成左右手目标。手部目标改变时，要协调头部杆与另一只手，避免让某一根杆持续钉住身体、另一根杆硬拉。头部杆可承担主要身体跟随，另一只手可能保留支点，也可能随身体平移，必须按具体动作分别采样。

反馈检查应同时关注三个杆端、上身与腰部的相对朝向、腿部姿态、角色是否整体平移以及回位余差。关节外观异常时，应降低这一组目标的幅度或停止；不能仅凭舵机还在单轴角度范围内就继续。

后续标定需要在已测轨迹附近分别增加手部横向和纵向目标，逐条验证躯干约束和被动关节响应；4 号的机械响应、当前图像到毫米的变换及任意人体姿态到六路 PWM 的逆映射仍未完成。本轮结果提供的是可复核的局部联动路径。
