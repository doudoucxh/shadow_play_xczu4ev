## 使用方法

1. 保存素材后关闭旧窗口，重新打开根目录“总线舵机示教上位机.cmd”。
2. 选择“实物 / PS串口”、COM17，连接后选择所需轴，点击“检测所选舵机”。
3. 用“打开轨迹…”加载完整的实际录制文件；编辑工程则在编辑器打开，检查并预览，再应用到主窗口。
4. 确认所选轴都有实际角度，并勾选现场确认；首次试放可使用0.5倍速。
5. 点击“③ 缓慢到首帧”，等待到位，再点击“④ 回放所选轴”。需要结束时使用“停止当前动作 / Esc”。

完整轨迹、素材来源、轴集合、限位、限速、首帧误差及新鲜反馈检查仍生效。模拟素材不能驱动实物。电脑软件手动启动；板子启动和连接只进入待命，不会自动回中或播放。
