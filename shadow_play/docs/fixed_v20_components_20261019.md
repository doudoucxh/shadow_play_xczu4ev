# 固定轨V20首段前置检查

用户明确暂不调滑杆，要求实物演示固定轨独立动作，并再次确认十路135°中位、无卡住、滑轨固定、现场可断电。新读为标准UART镜像下的OFF0，当前中位来源另存`fixed_v20_start_reference_20261019.json`，不改旧计划或把寄存器当实际轴角。

源目录的A01要求虎头抬起、尾末配合扭动，但视觉点没有可直接下发的PWM。其它动作也缺实测路线，TT与当前虎脚接杆定义存在差异。此次先执行虎头两轴的小幅准备，不能称为A01或正式V20演示。没有播放音频。

| 检查 | 指令范围 | 帧数 / 用时 | 正常停点 | 画面观察 |
|---|---|---|---|---|
| 7号横向 | 1500→1540→1500μs | 226 / 9.616秒 | OFF227 | 虎头杆横向响应可见，返回接近出发姿态 |
| 8号原视角 | 同上 | 226 / 9.598秒 | OFF454 | 未确认抬头或连杆位移 |

每次只有所选一路启用，其余九路关闭。三次均采纳完整226帧、最大相邻指令1μs；正常帧边界关闭，最终OFF681、十路指令1500μs、armed=false、enabled_mask=0、faults/pending=0，无实际角度反馈。完整板端日志、连续序号/掩码/路线、原锁摘要与两个安装清单已独立核验。软件正常采纳不能证明8号实际转动，暂不能确定供电、信号或传动故障。

Sony原会话未产出画面，使用既有工具恢复28800秒取景后核验连续新帧；手机调整后重新采样。三次共66张阶段图，Sony最大帧龄约68ms、手机63ms，原图及完整串口日志在忽略目录`.review_work/fixed-v20-return-20261019`。主机每0.3秒续租前检查两路新鲜度、帧号、JPEG及采集会话；失帧停止租约，板端期限1.5秒。助手在阶段后检查画面；租约不做逐帧碰撞识别，也未建立五杆毫米坐标、实际轴角或空间映射。

`fixed_v20_probe.py`复用已有小幅路线、单轴执行、停止及租约逻辑，增加本次独立来源、当前标准UART镜像/十路引脚门控，保持旧模式不变。原模式仅接受本次OFF0的7号和完成7号后的OFF227的8号；近景新模式只接受8号原始完成日志及OFF454。相同幅度没有自动增加，不能从OFF681再运行任一旧计划。使用前消费一次性标记，异常原地关闭，不重ARM、不自动回程或下一轴，原事故锁保留。

两个独立SD目录各核验8项清单：`fixed-v20-probes-20261019`保存原两段程序，`fixed-v20-closeup-20261019`保存增加近景模式的版本；前者没有被后者覆盖。Git源码为包含两模式的最终版本，旧SD文件摘要以各自MANIFEST为准。安装只传数据和检查语法，不启动动作服务。七项离线检查通过；没有切换FPGA、修改启动文件或发送滑杆报文。
