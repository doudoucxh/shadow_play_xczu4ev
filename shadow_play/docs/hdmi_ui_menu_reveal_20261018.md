# 主页三个入口展开优化（待板端部署）

用户明确指出卡顿位置是“主页挑出三个小入口的时候”，并要求助手帮助登录 COM17。已打开本机密码隐藏输入窗口；密码只用于串口登录，不保存、不进入日志。窗口起初继承隐藏启动状态，已单独显示到前台并确认可见。当前仍在等待用户填写密码，尚未登录、未安装补丁。

## 定位与修改

原主页对 `grid-template-rows` 和 `row-gap` 做 480 ms 动画。菜单展开时，皮影区域高度连续变化，ResizeObserver 反复调用画布尺寸调整与皮影绘制。菜单切换还执行整页 `render()`，刷新隐藏模式和装饰层。

板端宽度范围内改为固定主页布局，提前保留 110 px 的入口区域；展开时只对三张卡片做 280 ms 位移和 220 ms 淡入，第二、第三张分别迟 25/50 ms。皮影区域大小不变，卡片沿用深褐与旧金色。菜单切换仅更新本身的显示/无障碍状态；其它页面渲染、点击入口后的旧纸翻页、返回、Escape 和隐藏菜单禁用行为保留。

该修正与上一轮 `PacketReader` 重复整帧读取修正共同准备部署。它们尚未上板，不能将本机验证等同板端流畅度通过。
