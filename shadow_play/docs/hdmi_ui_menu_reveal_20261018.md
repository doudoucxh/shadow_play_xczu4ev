## 最终实现

- 固定板端主页网格，菜单切换只更新自身状态，避免缩放/重绘皮影。
- 主页旧书纹理、装订和多层阴影预渲染为 `board-cover.jpg`，角色和所有文字/按钮仍为独立内容；状态栏不烘焙进图片。场景边缘使用静态晕影。
- 取消板端三卡片的滑入/淡入，点击后下一次绘制直接显示；隐藏菜单仍 inert，Escape/收起/重开和进入模式均保留。进入模式的纸张翻页不变。
- 一并安装 PacketReader：同一发布文件仅检查头和文件身份，新文件才读取像素，帧龄与内容检查保持。

以同一 XTest 点击脚本、每次 1.2 秒观察窗口读取新帧 CRC，记录画面变化时刻。最后变化时间包含鼠标/悬停，不是物理屏延迟测量，也不能换算为动画帧率。

| 操作 | 原版本最后变化 | 最终版本最后变化 |
| --- | ---: | ---: |
| 第一次展开 | 841.0 ms | 300.3 ms |
| 第一次收起 | 794.7 ms | 154.3 ms |
| 第二次展开 | 1029.7 ms | 125.2 ms |
| 第二次收起 | 946.7 ms | 135.4 ms |

固定布局与减少重复读帧单独安装后仍有明显停顿；直接取消动画但不缓存封面时仍需约 0.55–1 秒。加入静态封面后出现上述改善。不能将联合优化结果全部归因于 PacketReader。

浏览器页面可见；激活窗口、显式软件刷新时钟试验均未带来改善，临时诊断、激活调用及刷新参数已撤除，包括 profile 中残留的参数。没有保留这些试验为正式修正。
