# 十路舵机与双丝杆手动标定

双击项目根目录 **机构手动调试与边界标定.cmd**，或 `shadow_play/tools/open_mechanism_calibration.cmd`。窗口默认进入模拟模式，不连接硬件、不回放姿态。

## 当前能做什么

- 人工逐路发送0–270°标称角度或500–2500μs脉宽；支持0.5/1/2/5°点动步长。已启用的其他舵机持续保持，便于保持整机姿态；未启用轴不会自动回中。
- 各舵机的引脚固定显示，4号为G13。实际轴角没有反馈。首次启用该路不能保证缓慢接近；点动只相对正在保持的指令计算。
- 丝杆1对应武松1605、标称600mm行程；丝杆2对应老虎1204、标称500mm行程。界面预填标称行程，尚未将端点认定为安全界限。
- 可录入两根丝杆的尺量位置和机械参数，记录当前位置为零点，模拟按毫米点动，手动保存行程范围。
- 保存“可用姿态 / 接近危险 / 禁止姿态”样本，以及十路指令、输出状态、位置来源、两丝杆位置、杆长/零点等结构备注。
- 明确设置单轴软限位和多维禁止组合，并检查从起点到目标的整个直线指令段。两个端点都不在禁区，但途中穿过禁区，也会被拒绝。
- 自动保存JSON，可导出CSV。数据文件可直接交给后续剧本与丝杆控制开发使用；载入文件不恢复输出。

**真实丝杆运动尚未接入。** 当前电机资料包括Emm/X多种固件及只有发送功能的FPGA串口示例；尚缺两台实物的固件、通信接线/设备、地址、细分和限位设置。软件没有猜测引脚或向未知串口发运动命令，实机丝杆移动按钮禁用。4/5mm导程只保留候选，不用来执行毫米换算。`manual_mechanism_setup.json`记录已知规格和待确认项。

## 建议的测量顺序

1. **先练习模拟。** 连接/开始模拟，勾选观察确认，逐个发送舵机目标。到“两根丝杆”页录入模拟位置，填行程后用±按钮移动。所有模拟样本有来源标签，不要混入真实机械标定。
2. **新建结构版本。** 给这一套杆长、云台安装、滑轨零点起唯一名称，例如 `杆长A_左侧零点_20261016`。备注写明五根杆长、零点位置、左右定义和当前接法。滑杆、改扎带、换齿位或改变零点后应新建版本。
3. **实机舵机准备。** 关闭其他串口/舵机工具；板端登录root并加载当前十路PWM镜像。运行 `powershell -NoProfile -ExecutionPolicy Bypass -File shadow_play/tools/install_mechanism_calibration_service.ps1 -PortName 实际COM号`。安装只传程序并语法检查，不启动电机。
4. **进入实机模式。** 选择PS串口并连接，只读核对输出。你在旁能立即断电、检查活动余量后勾选确认，再逐轴手动建立合适的保持姿态。其余已启用轴继续保持；没有一键全轴启用或自动扫描。
5. **录入尺量位置。** 在驱动接通前，可以手动移动并尺量丝杆位置后输入，标为人工测量；如果移动过、基准丢失或电机位置不确定，点“位置未知 / 基准失效”。“当前位置记为零”只记录位置，不驱动回零；已有数据时改变零点需新建结构。
6. **固定两根丝杆的位置，改变一条舵机指令。** 每次小步调整后观察，记下可用姿态和接近危险的姿态。备注写具体哪两根杆、哪一侧、间隙多少，以及接近方向。不需要故意撞击来记录禁止样本。
7. **换一组丝杆位置重复。** 丝杆位置变化后，检查新的舵机组合。暂时未接驱动时仅录入实测位置；真实移动按钮会在驱动信息确认、适配和验证后开放。
8. **明确录入禁止区间。** 样本标签本身不自动成为禁区。到“限位与危险组合”勾选有关舵机和丝杆，填区间并命名。区间中的各条件同时成立才属于该组合；不应把一次危险点外推成完整碰撞面。
9. **保存并导出。** 自动文件位于 `shadow_play/logs/mechanism_calibration/calibration_*.json`；手动保存JSON可自选路径，CSV方便核对。把JSON和CSV一起提供；JSON含完整边界、结构与来源。

## 边界例子

如果现场观察“武松丝杆180–200mm，老虎丝杆220–240mm，1号角度150–160°且3号120–130°时，两根杆接近”，可以勾选这四项、填相应区间并命名“人物杆与虎头杆接近”。这是人工指定的禁止盒；并不证明盒外全部安全。界面角度以度输入，JSON内舵机区间以μs保存，丝杆以mm保存。

如果相关丝杆位置未知或舵机没有持续保持，无法可靠计算这些条件，软件会拒绝边界检查。停PWM后的历史寄存器不能重新变成当前位置。若需要继续使用已有边界，应先在现场建立已知、持续保持的姿态，再用“导入同结构边界”接入同一结构版本的限制；导入会检查当前姿态，不发运动。不能用改序号、改来源或旧数据冒充恢复起点。

记录错误或需要细化时，可在停机后删除选中禁区、禁用单轴限位或放宽数值；修改前会另存`*_before_edit_*.json`旧版本，观察样本保留。活动输出期间不能借导入文件放宽已有约束。

## 输出与停止

“停止全部舵机 / Esc”停止当前服务的舵机输出；真实丝杆驱动尚未连接，因此不会虚报已经给丝杆发出停止。关闭或断开连接终止串口心跳，板端最终关闭已持有输出；通信超时不自动重发运动。停止PWM不是断电，机械遇到异常仍需直接断开电机电源。

板端`attended-mechanism-v1`仅供现场人工逐轴调试，保留原事故锁快照，不给剧本或定时任务开放回放。一次只改一路，使用当前序号和输出掩码验证归属；保留其他正在输出的轴。看门狗掉保持、故障或锁变化会停，必须人工停止并检查后才能再次操作。

这些记录提供后续防碰约束依据，不是完整几何碰撞模型。直线指令检查不能覆盖柔性变形、间隙、回差、运动不同步或未测障碍；正式丝杆执行器还必须读取同结构边界、监控位置和限位信号。
