# 主控 USB 音响播放记录（2026-10-14）

用户要求通过主控上新连接的音响播放桌面文件 `武松打虎（2）.wav`。
本次使用独立音频进程，未启动演出总控、发送舵机指令、解除动作锁或操作相机。

## 设备与素材

- 主控：`shadowdpupetalinux`，Linux 5.15.36，AArch64；通过 COM3 / 115200 串口访问。
- 声卡 0：icSpring 相机，仅有采集通道。
- 声卡 1：Jieli Technology USB Composite Device，USB ID `4c4a:4155`。
- 输出设备：`/dev/snd/pcmC1D0p`，48 kHz、双声道、S16_LE。
- 初始混音器：`PCM Playback Switch=On`，`PCM Playback Volume=119,119`（范围 0～147）；保持该设置。
- 源 WAV：44.1 kHz、双声道、PCM16，11,837,518 字节，67.105669 秒。
- 源 SHA-256：`950e52cc19d84877327e2a399ec5e078ed76daece6e358a61c0679af2114db5e`。
- 串口传输副本：48 kHz、双声道、128 kbit/s MP3，1,074,861 字节。它是有损播放副本，原 WAV 保持不变。
- MP3 SHA-256：`e001fb858ab32e4d0217bd7c5262667f8f077025e12be19fb21b82a1a8bd13e7`。

主控没有 aplay、libasound 或 GStreamer 音频插件。因此增加独立工具
`tools/usb_audio_play.c`，使用 TinyALSA 访问内核 PCM，使用 minimp3 解码。
`--check` 只解码，不打开声卡；实际播放必须显式指定声卡、设备和增益。
播放仅接受 48 kHz 双声道 MP3，遇到输出失败或欠载退出，结束前排空缓冲。

## 构建与临时部署

依赖固定到以下上游版本，下载目录位于被 Git 忽略的 `.board_work/audio-20261014`：

- [TinyALSA](https://github.com/tinyalsa/tinyalsa/tree/bbdba1e208f402c5b7d5cb3d42307a3db9f6bb1c)：`bbdba1e208f402c5b7d5cb3d42307a3db9f6bb1c`，保留 LICENSE、NOTICE。
- [minimp3](https://github.com/lieff/minimp3/tree/ea99364f61c14656440e8d77e9c233ccf3124633)：`ea99364f61c14656440e8d77e9c233ccf3124633`，使用 `minimp3.h`、`minimp3_ex.h`，保留 LICENSE。

在仓库根目录使用 Vitis 2022.2 自带交叉编译器：

```powershell
$audioCC = 'D:\xilinx\Vitis\2022.2\gnu\aarch64\nt\aarch64-linux\bin\aarch64-linux-gnu-gcc.exe'
$audioDeps = '.board_work/audio-20261014'
& $audioCC -O2 -s -std=gnu11 -D_POSIX_C_SOURCE=200809L `
  "-I$audioDeps/tinyalsa/include" "-I$audioDeps/minimp3" `
  shadow_play/tools/usb_audio_play.c `
  "$audioDeps/tinyalsa/src/pcm.c" "$audioDeps/tinyalsa/src/pcm_hw.c" `
  "$audioDeps/tinyalsa/src/limits.c" "$audioDeps/tinyalsa/src/snd_card_plugin.c" `
  -o "$audioDeps/usb_audio_play" -lm -ldl
& $audioCC -O2 -s -std=gnu11 -D_POSIX_C_SOURCE=200809L `
  "-I$audioDeps/tinyalsa/include" "$audioDeps/tinyalsa/utils/tinymix.c" `
  "$audioDeps/tinyalsa/src/mixer.c" "$audioDeps/tinyalsa/src/mixer_hw.c" `
  -o "$audioDeps/tinymix"
ffmpeg -nostdin -v error -i 'D:\Desktop\武松打虎（2）.wav' `
  -ar 48000 -ac 2 -c:a libmp3lame -b:a 128k -map_metadata -1 -n `
  "$audioDeps/wusong-2-48k.mp3"
```

播放器 SHA-256：`8684834abfc45f2823c4f3992ccd15b8c5bf3150b2757d7000b7a462cd59866d`。
播放器、tinymix 和许可证一起打包，经 `tools/board_transfer.ps1` 传输并校验 SHA-256。
音频另行传输并校验。运行文件位于板端 `/tmp/audio-player-20261014/`，
音频为 `/tmp/wusong-2-48k-20261014.mp3`，均为临时文件，重启后可能消失。

本次使用独立临时服务 `piying-audio-once-20261014.service` 完整播放一次，
软件增益为 0.75，最长运行 90 秒；不设置开机自启或循环播放。
重新连接后声卡编号可能变化，复用前须读取 `/proc/asound/cards` 和输出格式。
