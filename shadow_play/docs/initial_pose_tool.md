# 一键设定十路舵机初始角度

入口是项目根目录 `一键设定舵机初始角度.cmd`，或 `tools/open_initial_pose.cmd`。2026-10-18 用户明确要求制作一键设定所有舵机初始角度的小程序；本工具是新的人工十路目标入口，独立于旧的单轴例外和一次性剧本路线。

默认十路均为标称135°/1500μs装配参考。十路可以分别填写，界面即时显示对应脉宽；“填入全部135°”、保存、载入仅修改表格，不驱动机构。配置保存为JSON，默认目录 `shadow_play/logs/servo_initial_pose`，不保存登录凭据。4号引脚固定为G13。表中控制部位及十路次序沿用现有通道表，左右手身份不因人物转身而交换。

使用步骤：

1. 双击入口，填写或载入十路初始角度。初次默认135°不代表机构此刻已在中位。
2. 选择PS调试串口，当前默认COM17；确保板端已登录root，其他串口工具关闭，再点击“连接板子”。连接只读取状态，要求全部输出关闭，拒绝接管其他服务的活动输出。
3. 现场核对全部目标与杆件/鱼线联动空间，守着断电开关，勾选窗口中的现场确认，再点击“一键设定全部初始角度”。它在一次提交中启用十路并发送这十个目标；不分轴自动巡回或反复回放。修改表格、载入、连接或断开都会撤销此前确认，下一次发送需重新勾选。
4. 收到十路完整回执后持续保持，直到“全部停止”、Esc、断开或关闭窗口。需要换目标时先停止，再修改并重新确认。停止PWM不是切断电源，也不能保证停止后皮影姿态不变。

所有角度都是电气目标，没有实际轴角反馈。初次启用可能快速转动，程序没有用复位寄存器伪造起点或宣称限制首次速度。填写范围沿用历史各路内缩限制：`10–260 / 95–260 / 10–260 / 50–170 / 70–260 / 50–170 / 50–190 / 100–190 / 70–200 / 50–170°`。这些范围来自既有观察与限制，不证明接杆后的十路组合或中间路径安全。不得把“指令已收到”当作实际到位、联动标定完成或V20路线通过。

专用板端服务为 `attended-initial-pose-v1`，位于SD的 `/run/media/mmcblk0p2/piying/servo-initial-pose-20261018`。服务只接受完整十路初始目标、当前序号及当次人工确认，且仅从干净OFF状态开始。原事故锁与运行锁不删除，专用目录另有锁；普通驱动仍受锁约束。许可仅在核对过的这一组手动目标提交期间有效，不开放剧本、任意回放或滑轨驱动。

板端核对完整十路采用值、掩码、序号和故障；状态意外变化、锁变化、采用超时或通信失联后停止，不自动重新ARM。命令ID去重，过期序号拒绝；相同请求即使在停止后重放也不会再次执行。串口后台独立维持硬件看门狗心跳，窗口不使用主线程阻塞串口。

首次安装或更换板端目录时，执行 `tools/install_initial_pose_service.ps1 -PortName COM17`。安装器校验11个归档文件（10项运行清单加MANIFEST），编译检查Python源文件，创建独立目录，不改旧服务、启动镜像或HDMI运行清单，不加载FPGA、启动控制服务或发送运动。若已有不同版本，拒绝覆盖，需先审查。它使用本机已有Python和pyserial运行时，不是脱离运行环境的独立EXE。

本轮验证：新增12项测试通过，原单轴/回中相关17项通过，共29项；窗口启动、断开时禁止发送、编辑撤销确认及按钮可见检查通过。实际COM17连接取得新服务状态，序号0、十路关闭、faults/pending=0；随后只停止和退出，没有调用初始化或产生真实舵机运动。新工具的十路初始化仅经模拟寄存器验证，实际带杆效果未执行。部署及无凭据证据见 `../config/initial_pose_tool_20261018.json`。
