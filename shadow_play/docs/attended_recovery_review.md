# 人工监护带杆恢复：离线审核入口

当前交付的是 `integrations/calibration/attended_recovery_review.py` 的计划审核器，**不是硬件执行器**。不导入设备驱动、不解除动作锁、不部署到板端，也没有执行开关。已有空载回中程序不变。

用户明确要求复位，可以记录为本次 `operator_authorized`，无需反复索取相同授权。但授权不是角度反馈，也不能证明回程联动。

审核允许带杆方案，不强制要求拆杆；仍需已核验且未被移动的起点、现场监护、活动余量和带杆路线复核。起点来源只能是实测轴角或已观察确认且此后未改变的指令姿态；旧寄存器和目测估计不算反馈。所有十路终点为装配参考 1500 μs，不能以 0°替代。

审核每帧十路、20 ms 节奏、最长60秒、相邻帧不超过24 μs。通过只表示可进入执行器审查，不证明机械余量，也不赋予硬件运行能力。后续执行器还需独占设备、起点状态核对、取消和超时停机、日志、异常禁止重试及动作锁保留测试。

目前所有轴都曾手动转动，因此不能生成真实已核验起点。不得把测试用虚构起点用于板端，也不得把测试通过称作复位成功。

离线调用：`python integrations/calibration/attended_recovery_review.py PLAN.json`。未满足条件返回2；通过审核返回0，始终输出 `execution_available: false`。
