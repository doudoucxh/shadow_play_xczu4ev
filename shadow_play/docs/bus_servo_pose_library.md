# 第二部分：画画动作位置库上位机

2026-10-30，版本 `2026.10.30-pose-r1`。双击项目根目录 **`画画动作库上位机.cmd`**。

这是第二部分的逐项位置录入工具。动作名称、标识和人物示意图直接读取现有 `hdmi_ui/source/catalog.json`：武松20个动作，使用1～6号舵机；老虎保留当前画画页面已有的“站立”，使用7～10号。所有位置初始为空，需要人工设定和读取，未迁移旧PWM角度。

## 录入一个动作

1. 在第一部分上位机中结束操作并断开串口。同一COM17不能由两个窗口同时连接。
2. 打开新工具，选择“实物 / PS串口”，确认COM17，点“连接”。左侧选动作，再点“检测当前角色”。连接板子与获得舵机反馈是两个步骤。
3. 选择一种摆姿方式：
   - **手摆**：确认现场条件，扶稳机构，点“当前角色卸力 / 手摆”，调整至该动作姿态。
   - **填写角度**：先点“实际位置填入目标”，勾选需要调整的轴，修改目标角度，设置“最短到达 / 秒”，点“设置勾选角度”。程序根据新读实际位置自动延长过短的到达时间；手动设角沿用当前30°/秒限制，角度范围保持10～260°。输入和切换动作不发送运动。
4. 等姿态稳定，填写可选备注，点 **“① 读取实际位置并保存此动作”**。这里重新读取当前角色的全部轴，勾选框只决定手动设角范围，不缩减保存轴。目标框中的数值不会直接当作实际位置保存。
5. 需要检查时，点 **“② 调用已保存姿势”**。只向当前角色发目标，等待到达时间后重新读反馈，误差不超过2°才显示到位通过。可通过停止按钮或Esc中止。单个姿势直达不保证杆件路径无碰撞，现场检查空间的要求与第一部分一致。
6. 选下一个动作继续录入。左侧区分“未录入”“实物已录入”“模拟已录入”，顶部显示进度。

## 文件与重新打开

- 每次读取保存后自动写入窗口底部所示文件。默认 `shadow_play/logs/bus_servo/pose_library/画画动作位置库.json`。
- 文件含画画目录标识、舵机配置指纹、角色/动作标识、实际位置、各轴采集时间、来源、摘要及备注。
- 同名 `.history` 文件夹保留旧文件版本；每次写入使用临时文件后原子替换。检测到文件已被另一窗口改动时拒绝覆盖，需另存或重新打开。
- “打开动作库”用于恢复已有文件；“动作库另存为”用于复制备份并把后续自动保存切换到新路径。只打开文件或选择动作不会发运动。
- 如果磁盘写入失败，新读取的位置保留在窗口内，状态会提示未保存；应另存后再关闭。关闭仍会立即请求停止。
- 实际录入文件和历史版本属于本机表演数据，位于Git忽略目录，不上传到源码仓库。源码和说明通过Git备份。

## 离线练习

默认“离线模拟”，点连接，再点当前角色卸力；填写目标后点“模拟手摆到目标”，读取保存。模拟数据会明确标记，并在GUI及执行线程两层禁止调用到实物。要录入实物动作，切换实物模式重新读取对应动作；替换已有动作时会提示确认。

## 当前范围与验证

此工具通过现有双总线服务读取、卸力和手动设角，无需更新SD、FPGA或自启。它保存静态动作位置，不记录第一部分那样的连续轨迹，也尚未把位置库接入板端“识别画画后执行”流程。

194项总线相关离线测试通过，其中新增13项；独立隐藏Tk完成21项动作切换、1200×850与1060×780布局边界检查，以及模拟手摆、读取、保存、重开、调用到位、角色隔离和停止时取消录入。真实新窗口已通过可见布局核对，默认离线且未连接。未连接实物串口或替用户试动，不把模拟到位结果称为实物验收。
