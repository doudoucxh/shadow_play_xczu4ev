# 人工监护单路回中

入口：`tools/open_attended_center.cmd`。这是独立窗口，旧角度调节窗口仍受原运动锁约束。

2026-10-15 用户明确要求现场逐路观察回中后，新增限定的人工操作入口：选择一轴，勾选现场监护和活动空间确认，再在弹窗确认。只发送该轴1500 μs（标称135°），其余九轴关闭，最长5秒；可提前点击停止PWM或按Esc。不是任意角度调节、全轴回中或剧本启动入口。

初次从未知位置回中可能较快且幅度较大，软件不能限制这段速度。没有实际轴角反馈。其他轴关闭不表示它们保持位置；单轴回中可能牵动整个连杆机构。停止PWM不是断电或机械锁定。这个入口不承诺带杆路径已验证，也不把停止后的指令作为实测起点。

板端服务为`attended-midpoint-v1`。专用设备实例仅允许带当前序号和人工确认的单次固定中位请求；普通PwmDevice仍受事故锁约束。锁文件不删除，内容变化终止当前输出。拒绝任意脉宽、多轴、输出未关闭、故障、旧序号和无确认请求。重复传输ID不重复执行。使用既有FPGA看门狗与串口心跳；断线不自动重连/重试。

安装器只传文件和做语法检查；打开窗口不连接，连接只读。动作日志位于`logs/attended_center`。六项离线测试及Tk启动检查通过；COM3只读连接验证服务正确、OFF34017、十路关闭。尚未发送真实回中指令，机械效果未验证。

这只是人工回中例外，不更改已审核固定路线执行器，不授权自动定时任务执行，也不解除失败剧本路线禁用。
