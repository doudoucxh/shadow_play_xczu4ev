# 人工监护单路角度与边界调试

## 2026-10-19 主调试入口已切换并部署

用户希望通过 `舵机角度调试.cmd` 直接进行现场手动诊断。此前该主入口仍启动 `unloaded-manual-v2`，会被历史运动锁拦截；现在改为启动独立的 `attended-angle-v1`。这条人工单轴路径不依赖旧剧本计划或已消耗的实测序号，也不要求拆杆或删除历史锁。通用自动剧本没有解锁。

新版部署在SD独立目录 `/run/media/mmcblk0p2/piying/attended-angle-20261019`，不覆盖旧服务，含完整运行依赖和本地动作锁。Windows默认COM17，选轴只显示编号和正确引脚（4号G13），实物杆件对应由现场核对，避免沿用当前尚有出入的人物/老虎标签。

使用方法：关闭旧调试窗口，重新双击项目根目录 `舵机角度调试.cmd`；选择COM17并连接，选1–10号，勾选现场监护确认后输入角度或脉宽，点击“发送目标”。可输入0–270°标称角度或500–2500μs；可同轴更新及单次点动，持续保持至手动停止。换轴先点“停止PWM”，Esc同样停止；断开或关闭窗口结束心跳并请求关闭输出。打开窗口和连接均不发送角度目标。

保留电气范围、现场确认、当前序号、单轴掩码、有效PWM镜像、ACK核对、故障/通信失败保护及FPGA看门狗。历史锁原样存在时人工路径可用，锁内容改变会停止并要求重新检查；不是任何故障状态下强制运行。0–270°仍是电气指令范围，首次目标没有实际角度反馈，不能保证从未知位置缓慢移动。

本次只读确认旧服务为OFF8119后退出，安装后十项MANIFEST逐文件校验通过。新版客户端真实连接COM17，返回 `manual_diagnostics_available=true`、`incident_lock_retained=true`，保持OFF8119、十路指令1500μs、faults/pending=0。只发送hello/status/heartbeat/off，没有发送move、ARM或角度目标；随后释放串口，板端服务空闲等待用户连接。20项离线检查和Tk窗口启动检查通过，真实目标输出效果仍由用户现场测试。

安装工具 `tools/build_attended_angle.py` 仅打包/安装和语法校验，不启动运动，不改变开机或FPGA。原图/串口原始日志不入Git，部署结果见 `config/attended_angle_deployment_20261019.json`。

## 历史：2026-10-16 角度调试版

用户要求将回中工具扩展为手动任意角度指令以测边界。现在双击 `tools/open_attended_center.cmd` 或 `tools/open_attended_angle.cmd` 均打开新版；旧的固定中位板端服务保留。

1. 关闭其它占用PS串口的窗口，板端登录root并已加载十路G13 PWM镜像。用 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/install_attended_center_service.ps1 -PortName COM3` 安装服务；COM号按实际选择。安装只传文件和语法检查。
2. 打开窗口、选择串口并连接；连接只读，不会回中。选择1–10号舵机，确认现场监护和本次联动空间。
3. 输入 **0–270°标称角度** 或 **500–2500μs整数脉宽**，点击“发送目标”。可在同一路持续输出时改目标，或用±1°/±5°点动；回中按钮仍发送135°/1500μs。
4. 现场观察后点“记录下限”或“记录上限”，保存编号、引脚、脉宽、标称角度和序号。边界记录是人工观察，不自动成为剧本限位。
5. 点击“停止PWM”或按Esc停止。**持续保持，不再5秒自动停止**；换舵机前必须先停止。断开连接或关闭窗口结束心跳并停止输出。

0°是标称端点，不是回中；电气范围不代表机械可动范围。首次输出可能立即大幅转动，程序不能从未知实际角度保证缓慢接近。其余九路关闭，连杆仍可能牵动；停止PWM不等于断电。

服务`attended-angle-v1`仅接受人工选轴、现场确认、当前序号的单轴目标，禁止多轴和自动扫动。重复ID不再执行；故障、旧序号、其他轴已输出、锁内容变化均会阻止动作。原事故锁文件、通用PwmDevice限制和剧本失败路线不改；此入口不供定时任务使用。

命令日志和人工边界记录位于`logs/attended_angle`。没有实际轴角反馈，OFF后的历史指令不能作为当前位置。26项相关离线测试及窗口启动检查通过。本机当前只识别蓝牙串口，COM3不存在，因此新版板端安装/只读连接尚未完成，未发送真实角度指令。

## 历史：2026-10-15 固定中位版

入口：`tools/open_attended_center.cmd`。这是独立窗口，旧角度调节窗口仍受原运动锁约束。

2026-10-15 用户明确要求现场逐路观察回中后，新增限定的人工操作入口：选择一轴，勾选现场监护和活动空间确认，再在弹窗确认。只发送该轴1500 μs（标称135°），其余九轴关闭，最长5秒；可提前点击停止PWM或按Esc。不是任意角度调节、全轴回中或剧本启动入口。

初次从未知位置回中可能较快且幅度较大，软件不能限制这段速度。没有实际轴角反馈。其他轴关闭不表示它们保持位置；单轴回中可能牵动整个连杆机构。停止PWM不是断电或机械锁定。这个入口不承诺带杆路径已验证，也不把停止后的指令作为实测起点。

板端服务为`attended-midpoint-v1`。专用设备实例仅允许带当前序号和人工确认的单次固定中位请求；普通PwmDevice仍受事故锁约束。锁文件不删除，内容变化终止当前输出。拒绝任意脉宽、多轴、输出未关闭、故障、旧序号和无确认请求。重复传输ID不重复执行。使用既有FPGA看门狗与串口心跳；断线不自动重连/重试。

安装器只传文件和做语法检查；打开窗口不连接，连接只读。动作日志位于`logs/attended_center`。六项离线测试及Tk启动检查通过；COM3只读连接验证服务正确、OFF34017、十路关闭。尚未发送真实回中指令，机械效果未验证。

这只是人工回中例外，不更改已审核固定路线执行器，不授权自动定时任务执行，也不解除失败剧本路线禁用。
